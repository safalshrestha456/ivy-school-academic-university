# Ivy School - Academic University (Frontend Replica)

A pixel-perfect, responsive frontend replica of the [Ivy School - Academic University](https://ivy-school.thimpress.com/academic-university/) homepage.

## 🚀 Live Demo & Repository
- **GitHub Repository**: [https://github.com/safalshrestha456/ivy-school-academic-university](https://github.com/safalshrestha456/ivy-school-academic-university)
- **Live Deployment**: Deployed on Netlify / Vercel

---

## 📖 Project Overview
This project is a 100% faithful recreation of the Academic University demo theme by ThimPress. It focuses purely on UI precision, typography, interactive controls, responsiveness, and performance without requiring a WordPress backend.

### Key Sections Replicated
1. **Top Bar Header**:
   - Contact hotline `(+88) 1900 6868` and official email.
   - Interactive Dark/Light mode toggle switch with persistent localStorage theme state.
   - LTR / RTL layout direction toggle.
   - User account portal links (Register / Login) and search trigger.
2. **Main Navigation**:
   - Ivy School institutional crest logo.
   - Multi-level dropdown navigation (Home, Admissions & Aid, Academics, News & Events, About, Pages).
   - "Apply Now" call-to-action button.
   - Responsive mobile hamburger navigation drawer.
3. **Hero Section**:
   - Catchy typography banner: *"Learn Design Skills That Actually Get You Hired"*.
   - Primary and secondary action buttons (*"Explore Programs"*, *"Apply Now"*).
   - High-definition hero imagery showcasing university professors and students.
4. **About / Institutional Legacy**:
   - *"Discover An Institute Committed To Excellence"*.
   - 6-card metrics and feature matrix:
     - Our Academic Legacy
     - 1,500+ Diverse Students
     - 120+ Academic Professionals
     - 25+ Career-Focused Programs
     - 95% Graduate Career Success
     - Global Partnerships with world map background.
5. **Featured Academic Programs**:
   - Future-ready program cards with metadata (duration, academic level, delivery format):
     - *MS in Data Analytics*
     - *Master's in Web Development*
     - *Diploma in Animation*
   - Interactive nested program tabs and details.
6. **Learning Methodology**:
   - *"Learn Through Practice, Collaboration, And Real Experience"*.
   - 4 pillar highlights: Practice-Based Learning, Industry-Led Experiences, Flexible Study Options, Personalized Support.
7. **Admissions & Support Guidance**:
   - Dual split cards for *Admissions* and *Scholarships* with requirement tags and advisory imagery.
8. **Latest News & Research Updates**:
   - Editorial cards covering campus research, business partnerships, and technological innovation with author tags and publishing dates.
9. **Call-To-Action Banner**:
   - *"Take The Next Step Toward Your Future"*.
   - Dual buttons with campus life banner photography.
10. **Stay Connected / Newsletter**:
    - Subscription form with real-time interactive confirmation.
11. **Institutional Footer**:
    - Full 4-column directory (Institute, Study, Admissions, Get Started).
    - Social links and copyright footer.

## 🛠️ Built With
- **HTML5**: Semantic tags, accessibility attributes, scalable SVG assets.
- **CSS3**: Custom design tokens, Flexbox, CSS Grid, Elementor design system variables, dark mode styles.
- **JavaScript (Vanilla)**:
  - Dark / Light mode switching with localStorage persistence.
  - Sticky header with scroll detection.
  - Mobile drawer navigation toggle.
  - Interactive tabs.
  - Animated stat counters.
  - Newsletter interactive feedback.
  - Smooth anchor scrolling.
- **Assets**: Self-hosted local optimized WebP/PNG/JPG images for resilience and lightning-fast loading speeds.

## 💻 Local Setup & Development

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/safalshrestha456/ivy-school-academic-university.git

# Navigate into the project folder
cd ivy-school-academic-university

# Serve using any local web server, for example:
# Using Python:
python -m http.server 3000

# Or using Node / npx:
npx serve .
```

Open your browser and navigate to `http://localhost:3000`.
